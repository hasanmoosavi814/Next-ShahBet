# ⚽ Football Dashboard – Next.js 14

A modern, responsive football dashboard built with **Next.js 14 (App Router)**, **TailwindCSS**, **RTK Query**, and **Framer Motion**.  
Explore leagues, match fixtures, live stats, odds, and more – all in one place.

---

## 🚀 Features

- ✅ Modern landing page with animated feature cards
- ✅ Dynamic league listing with team info
- ✅ Interactive match fixtures by season
- ✅ Match details including stats, lineups, and events
- ✅ Responsive design for all devices
- ✅ Smooth animations using Framer Motion
- ✅ Fully typed with TypeScript
- ✅ Modular, scalable file structure
- ✅ Powered by [API-Football](https://www.api-football.com/)

---

## 🧱 Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org)
- **Styling**: [TailwindCSS](https://tailwindcss.com)
- **State/API**: [RTK Query](https://redux-toolkit.js.org/rtk-query/overview)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Icons**: [Lucide Icons](https://lucide.dev/)
